# Wispen

**Your private, Jarvis-style voice assistant for Windows.**
Say **“Hey Wispen”**: search the web, open apps, play music, read your screen, focus, in English or Hinglish.
Speech, AI and your data stay on your PC.

### ⬇ Download for Windows: [Lite](https://github.com/arnavaditya28/wispen/releases/latest/download/Wispen-Lite-Setup-x64.exe) · [Standard](https://github.com/arnavaditya28/wispen/releases/latest/download/Wispen-Standard-Setup-x64.exe) · [Max](https://github.com/arnavaditya28/wispen/releases/latest/download/Wispen-Max-Setup-x64.exe) · [Website](https://arnavaditya28.github.io/wispen/)

- **Install:** pick the edition for your PC (Lite for 4 GB RAM, Standard for 8 GB, Max for 16 GB + NVIDIA GPU) and run it. Not sure? Standard. You can switch editions later in Settings.
- **Updates:** automatic. Wispen shows a popup when a new version is out; one click installs it.
- **Windows says “Windows protected your PC”?** The installer isn't code-signed yet: click **More info → Run anyway**.
  Every update is digitally signed and verified by the app.
- **Requirements:** Windows 10/11 (64-bit), 4 GB RAM or more. An NVIDIA GPU makes voice faster but isn't needed.
- **Optional local AI:** install [Ollama](https://ollama.com), then `ollama pull llama3.2:3b`.

This repository only hosts Wispen's downloads and website. Wispen is free to use; its source code is private.
